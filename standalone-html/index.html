Backend API Connection Guide

Architecture Overview:

This standalone HTML edition currently operates in Offline Demo Mode utilizing browser localStorage. It does not send any student records over the network.


Connecting to the Production Node.js Server:

To connect this interface to the real backend running on port 5000:

  1. Start the backend server: npm.cmd start
  2. Login to obtain a JWT token: POST /api/auth/login with valid credentials.
  3. Set the HTTP request headers in your fetch calls: 
    Authorization: Bearer <TOKEN>
x-school-id: <SCHOOL_ID>
Content-Type: application/json
  4. Endpoints available: /api/students, /api/fees, /api/admissions, /api/attendance, etc.

See standalone-html/README.md for detailed instructions.
